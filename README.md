# Farmicon Landing Page

A modern, animated, and accessible landing page for Farmicon – an all-in-one platform for Indian farmers and the agricultural ecosystem.

## Tech Stack
- Next.js (App Router, TypeScript)
- Tailwind CSS
- Framer Motion (animations)
- Lottie (vector animations)
- react-fast-marquee (media mentions marquee)

## Features
- Sticky animated navbar with download button
- Hero section with full-screen animation
- About, Features, How It Works, Media, Testimonials, Download, and Contact sections
- Modular, reusable components
- Ready for future voice and translation features

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

---

**Structure:**
- `src/components/` – All React components
- `src/app/` – Main page and layout
- `public/` – Static assets (images, animations, etc.)
